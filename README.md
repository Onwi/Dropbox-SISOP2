# Dropbox-SISOP2

### Compile and Run server
from root dir move to server dir  
`cd server`  
then run `make` and it will compile the server into an executable `server`  
`./server name_server` will run the server  
 
### Compile and Run client 
from root dir move to client dir  
`cd client`  
then run `make` and it will compile the server into an executable `client`  
`./client username server` will run the client  

### Compile and Run name server 
from root dir move to client dir  
`cd name_server`  
then run `make` and it will compile the server into an executable `name_server`  
`./name_server` will run the name server
